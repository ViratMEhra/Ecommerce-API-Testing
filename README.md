# Ecommerce-API-Testing
Mock E-commerce API created using Node.js and Express for testing and validation using Postman
🎯 Project Overview

This project simulates an E-commerce Order Management API designed for testing and validation purposes.
It’s a mock REST API built using Node.js + Express, containing endpoints that return realistic data such as orders, payments, and totals.

The main goal of this project is to demonstrate manual and API testing skills using Postman — focusing on data validation, response correctness, and automation readiness.

💼 Role Context – (Testing Intern Perspective)

As part of the Testing Intern responsibilities, this project showcases:

Testing and validating REST APIs for data consistency.

Creating and documenting mock data for order, customer, and payment flows.

Performing manual and scripted testing using Postman.

Logging findings, edge cases, and improvements clearly.

⚙️ Tech Stack

Node.js – for creating the mock server

Express.js – for routing and handling API requests

JSON – for storing realistic mock e-commerce data

Postman – for validation and test automation
